# AutoCore — Система управления инвентарем двигателей

macOS-приложение для управления складом двигателей и моторов с поддержкой импорта из Excel.

---

## 📋 Что делает приложение

**AutoCore** помогает управлять инвентарем двигателей:
- Хранит информацию о брендах, типах двигателей и конкретных моторах
- Импортирует данные из Excel-файлов
- Отслеживает статус моторов (в наличии / продан)
- Ведет учет специфичных записей (ремонт, хранение и т.п.)
- Экспортирует данные обратно в Excel

---

## 🎯 Основная логика работы

### 1. **Структура данных**

Приложение работает с тремя основными сущностями:

```
Бренды (Brands)
  └── Двигатели (Engines) — типы двигателей у бренда
      └── Моторы (Motors) — конкретные экземпляры с серийными номерами
```

**Пример:**
- Бренд: `Subaru`
- Двигатель: `EJ251`
- Моторы: `EJ251-001`, `EJ251-002`, `EJ251-003`

### 2. **Статусы моторов**

Мотор может быть в двух состояниях:
- **В наличии** — `sold_date = null`
- **Продан** — `sold_date = дата продажи`

Статус определяется автоматически по полю `sold_date`.

### 3. **Типы листов при импорте**

При импорте Excel каждый лист может быть:

1. **Основной (двигатели)** — данные идут в основную таблицу `motors`
   - Требует настройки бренда и типа двигателя
   - Обязательно поле "НОМЕР ДВИГАТЕЛЯ" (serial_code)

2. **Специфичный** — данные для ремонта, хранения и т.п.
   - Хранится в отдельной таблице `specific_records`
   - Пользователь сам определяет поля (key-value в JSON)
   - Категории: Ремонт, После Дэна, После Толи, Хранение, Другое

3. **Пропустить** — лист не импортируется

## 🔄 Процесс импорта Excel

### Шаг 1: Анализ
- Приложение читает Excel-файл
- Показывает список всех листов с количеством строк и превью

### Шаг 2: Выбор типа
- Для каждого листа пользователь выбирает тип (Основной/Специфичный/Пропустить)

### Шаг 3: Настройка колонок ⭐ **Ключевой шаг**
- **Для основных листов:**
  - Пользователь вручную сопоставляет каждую колонку Excel с полем:
    - НОМЕР ДВИГАТЕЛЯ (обязательно)
    - Комплектация
    - Особые отметки
    - Количество
    - Коробка
    - Дата прихода
    - Дата продажи
    - Игнорировать

- **Для специфичных листов:**
  - Пользователь вводит имя поля для каждой колонки
  - Можно создать любое поле (например: "НОМЕР ДВИГАТЕЛЯ", "Ремонт", "Дата ремонта")
  - Данные сохраняются как JSON

**Важно:** Никаких автоматических предположений! Пользователь сам решает, что куда идет.

### Шаг 4: Preview
- Показывает, как данные будут сохранены
- Таблица с примененным маппингом
- Статистика (сколько моторов, новых брендов и т.п.)

### Шаг 5: Импорт
- Все данные сохраняются в одной транзакции
- При ошибке — полный откат (rollback)

## 🎨 Дизайн-решения

### Принцип: "Пользователь — источник истины"

**Почему так:**
- Excel-файлы могут быть в любом формате
- Нет единого стандарта названий колонок
- Автоматические предположения часто ошибаются

**Решение:**
- Пользователь сам настраивает каждую колонку
- Приложение показывает preview значений для удобства
- Но не делает предположений автоматически

### Минималистичный интерфейс

**Навигация:**
- Боковая панель: бренды, двигатели, категории
- Центральная область: список моторов
- Правая панель: детали выбранного мотора

**Фильтрация:**
- Сегментированный контрол: Все / В наличии / Продан
- Поиск по серийному номеру, коду двигателя, бренду
- Фильтры работают через вычисляемые свойства (не мутируют данные)

### Производительность

**Для больших данных:**
- Все моторы загружаются в память один раз
- Фильтрация происходит на уровне UI (быстро)
- Пагинация не нужна — все данные в памяти

**Для импорта:**
- Транзакции SQLite для атомарности
- Batch-обработка для скорости
- Прогресс-бар для обратной связи

## 🗂️ Структура базы данных

### Основные таблицы

**brands**
- `id` — уникальный идентификатор
- `name` — название бренда (уникально)

**engines**
- `id` — уникальный идентификатор
- `brand_id` — ссылка на бренд
- `engine_code` — код двигателя (уникально в рамках бренда)

**motors**
- `id` — уникальный идентификатор
- `engine_id` — ссылка на двигатель
- `serial_code` — серийный номер (уникально)
- `configuration` — комплектация
- `notes` — особые отметки
- `quantity` — количество
- `transmission` — коробка
- `arrival_date` — дата прихода
- `sold_date` — дата продажи (null = в наличии)
- `created_at`, `updated_at` — служебные поля

### Специфичные таблицы

**specific_sheets**
- `id` — уникальный идентификатор
- `name` — название листа (уникально)
- `created_at` — дата создания

**specific_records**
- `id` — уникальный идентификатор
- `sheet_id` — ссылка на лист
- `row_index` — индекс строки в Excel
- `data_json` — данные в формате JSON (key-value)
- `created_at` — дата создания

**Пример JSON:**
```json
{
  "НОМЕР ДВИГАТЕЛЯ": "EJ251-001",
  "Ремонт": "Замена прокладки",
  "Дата ремонта": "2025-01-15"
}
```

## 🔧 Архитектура

### MVVM (Model-View-ViewModel)

**Models** — структуры данных:
- `Brand`, `Engine`, `Motor`
- `ColumnMapping`, `SheetColumnMapping`
- `ImportRow`, `ImportPreviewSummary`

**Views** — SwiftUI интерфейс:
- `RootView` — главный экран
- `MotorListView` — список моторов
- `ImportWizardView` — мастер импорта
- `ColumnMappingView` — настройка колонок

**ViewModels** — бизнес-логика:
- `AppViewModel` — управление состоянием приложения
- `ImportViewModel` — логика импорта Excel

**Services** — работа с данными:
- `DatabaseService` — SQLite операции
- `ExcelImportService` — чтение Excel (CoreXLSX)
- `ExcelExportService` — запись Excel

### Потокобезопасность

- Все операции с БД через `DispatchQueue` (serial queue)
- Транзакции для атомарности
- `@MainActor` для UI-обновлений

## 🚀 Как использовать

### Импорт Excel

1. Нажмите "Импорт Excel" в тулбаре
2. Выберите файл .xlsx
3. Для каждого листа:
   - Выберите тип (Основной/Специфичный/Пропустить)
   - Настройте колонки (назначьте каждую колонку полю)
4. Проверьте preview
5. Нажмите "Импортировать"

### Работа с моторами

**Добавить мотор:**
- Кнопка "Добавить мотор" в тулбаре
- Заполните форму
- Можно выбрать существующий бренд/двигатель или создать новый

**Продать мотор:**
- Кнопка "Продать" в таблице или деталях
- Автоматически переключается на фильтр "Проданные"

**Вернуть в наличие:**
- Кнопка "Вернуть" для проданных моторов

**Редактировать:**
- Выберите мотор в таблице
- Измените данные в правой панели
- Для проданных моторов редактируются только "Особые отметки"

### Экспорт

- Кнопка "Экспорт Excel" в тулбаре
- Создает файл с листами:
  - Все моторы
  - Проданные моторы
