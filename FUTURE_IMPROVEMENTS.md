## 📝 Заметки

### Принципы развития
1. **Не ломать существующее** — все изменения обратно совместимы
2. **Простота превыше всего** — новые функции не должны усложнять UI
3. **Производительность** — новые функции не должны замедлять приложение
4. **Пользовательский опыт** — каждое изменение улучшает UX

### Процесс добавления функций
1. Создать issue с описанием функции
2. Обсудить архитектуру и UX
3. Реализовать в отдельной ветке
4. Протестировать
5. Code review
6. Merge в main
