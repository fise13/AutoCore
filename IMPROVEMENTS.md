# AutoCore — Полный список улучшений

Документ описывает предлагаемые улучшения для AutoCore: UI/UX, функциональность, доступность и опыт пользователей для всех категорий пользователей.

---

## 1. UI/UX улучшения

### 1.1 Навигация и структура

| Улучшение | Описание | Приоритет |
|-----------|----------|-----------|
| **Breadcrumbs** | Хлебные крошки при глубокой вложенности (например: Все → Subaru → EJ251) для быстрого возврата | Средний |
| **Сохранение состояния sidebar** | Запоминать раскрытые бренды, выбранную секцию при перезапуске | Высокий |
| **Быстрый переключатель (⌘K)** | Command Palette для поиска разделов, действий, моторов по номеру | Высокий |
| **Группировка в сайдбаре** | Счётчики рядом с «Все», «Проданные», категориями (например: «Проданные (42)») | Средний |
| **Drag & drop сайдбара** | Изменяемая ширина сайдбара перетаскиванием разделителя | Низкий |

## 7. Приоритизация (сводка)

**Сделать в первую очередь (Quick wins + высокий приоритет):**

1. Toast-уведомления вместо части alert’ов  
2. Сохранение состояния сайдбара и таблицы (колонки, ширина)  
3. Сортировка по колонкам в таблице моторов  
4. Настраиваемые колонки таблицы  
5. Command Palette (⌘K)  
6. Полноценные подсказки и справка по горячим клавишам  
7. Базовая доступность (VoiceOver, фокус, контраст)  
8. Статус синка в UI  
9. Шаблоны маппинга при импорте  
10. Краткий онбординг при первом запуске  

**Следующий этап:**

- Виртуализация таблицы при большом числе моторов  
- Фильтры по дате в бухгалтерии, категории расходов  
- Связь мотора со специфичными записями в карточке  
- Улучшения импорта (авто-маппинг, CSV)  
- Профиль пользователя и доведение экспорта одного мотора  

**Долгосрочно:**

- Графики и отчёты в бухгалтерии  
- Подписка, роли, расширенные интеграции  
- Дополнительные языки и платформы
